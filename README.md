# Ucapan Ulang Tahun

Halaman web statis ini adalah ucapan ulang tahun sederhana yang bisa kamu kirim ke pasanganmu.

## Cara pakai

1. Buka `index.html` di browser.
2. Klik tombol "Buka Ucapan" untuk menampilkan pesan dan confetti.

## Deploy ke GitHub

1. Buat repository kosong di GitHub.
2. Tambahkan remote, misalnya:
   ```bash
   git remote add origin https://github.com/username/repo.git
   ```
3. Push ke GitHub:
   ```bash
   git branch -M main
   git push -u origin main
   ```

## Kustomisasi

- Ganti teks pada `index.html` agar sesuai nama dan pesan pasanganmu.
- Edit warna di `style.css` jika kamu ingin tema lain.
